# Nataliia Evseeva — Engineering Portfolio

Standalone English engineering portfolio tailored to battery engineering and technical program management applications. The existing `engineering` website is not modified.

## Deploy with GitHub Pages

1. Create a new **public** GitHub repository named `tesla-engineering` under `natusikse`.
2. Upload **all contents** of this folder, keeping `index.html` in the repository root and `assets/` intact.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
4. Wait for GitHub Pages deployment. The expected URL is `https://natusikse.github.io/tesla-engineering/`.
5. Test the resume link and portrait on the published page.

The battery architecture diagram and interactive readings are explicitly illustrative, not a live hardware connection. Replace them with real project screenshots, measurements or photos if you wish to show project evidence.

The included resume is the latest locally available English PDF, `Nataliia_Evseeva_Tesla_CV_Burgundy_Fixed.pdf`.
